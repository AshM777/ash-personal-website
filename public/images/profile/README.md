# Profile Images

This folder contains the profile images that rotate on the homepage.

## Instructions

Add your portrait images here with the following names:
- `1.jpg` (already exists)
- `2.jpg`
- `3.jpg`
- `4.jpg`

**Important:**
- Use portrait orientation (vertical)
- Images will be cropped to fit a fixed container (h-96)
- Use high-quality images for best results
- Recommended dimensions: at least 800px wide × 1000px tall

The "change image" button on the homepage will cycle through these images.
